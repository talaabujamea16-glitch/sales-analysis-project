# تحليل المبيعات الذكي 📊

مشروع تحليل بيانات متكامل يقوم ببناء مسار (Pipeline) كامل يحوّل بيانات مبيعات خام إلى تقرير تحليلي جاهز، باستخدام Python وأدوات علم البيانات الأساسية.

## هدف المشروع

بناء نظام تحليل بيانات كامل يشمل:
- جلب البيانات مباشرة من منصة Kaggle عبر واجهة برمجية (API)
- تنظيم البيانات باستخدام مبادئ البرمجة الكائنية (OOP)
- معالجة الأخطاء والاستثناءات (Exception Handling)
- تحليل رقمي سريع باستخدام NumPy
- تنظيف وتحليل البيانات باستخدام Pandas
- تصدير النتائج في تقرير Excel جاهز

##  الأدوات والمكتبات المستخدمة

- **Python** – لغة البرمجة الأساسية
- **Kaggle API** – لجلب البيانات مباشرة
- **Pandas** – لتنظيف البيانات وتحليلها
- **NumPy** – للعمليات الحسابية السريعة
-    Excel  ومن  ثم  بتصدير النتائج إلى

## البيانات المستخدمة

تم استخدام Dataset مبيعات (Sales Dataset) من منصة Kaggle، حيث يمثل كل صف في البيانات معاملة بيع واحدة، تتضمن معلومات عن العميل، المنتج، الكمية، السعر، والمبلغ الإجمالي.

## ⚙️ طريقة التشغيل

1.تنسخي (Clone) المستودع على جهازك:
git clone https://github.com/talaabujamea16-glitch/sales-analysis-project.git

2. ثبّتي المكتبات المطلوبة:
pip install -r requirements.txt

3. أعدّي بيانات اعتماد Kaggle API الخاصة بك (ملف `kaggle.json`) حسب [تعليمات Kaggle الرسمية](https://www.kaggle.com/docs/api).

4. افتحي ملف المشروع (ipynb) عبر Jupyter Notebook أو VS Code ونفذي الخلايا بالترتيب من الأعلى للأسفل.
